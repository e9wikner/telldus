## Threat Model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host CI/build script -> Docker buildx | Build script automates image construction; must not leak registry credentials or build secrets |
| Smoke test script -> running container | Test script starts containers; must clean up to avoid resource leaks |

### STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Information Disclosure | build-docker.sh registry push | mitigate | --push mode requires explicit flag and registry tag; no hardcoded credentials in script; operators provide credentials via docker login |
| T-05-03-02 | Denial of Service | Smoke test containers left running | mitigate | All tests use --rm for automatic container removal; test_default_daemon uses docker inspect (no running container); mktemp -d + trap rm for temp files |
| T-05-03-03 | Tampering | Unverified image promoted to registry | mitigate | Smoke tests run before any push; build stage runs CppUnit tests; only passing images are considered valid |
