## Threat Model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docker host -> container | Operator provides config file via bind mount; container must not execute arbitrary code from it |
| Entrypoint script -> daemon/CLI | Script dispatches to telldusd, tdtool, or tdadmin; must not allow injection of other commands |

### STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Elevation of Privilege | Entrypoint script dispatch | mitigate | Exact string match on "$1" for "tdtool" and "tdadmin"; all other values fall through to telldusd --nodaemon, preventing arbitrary command execution |
| T-05-02-02 | Denial of Service | Signal handling without init system | mitigate | tini runs as PID 1, forwarding SIGTERM to the entrypoint script and ensuring clean shutdown; without tini, docker stop would SIGKILL after timeout |
| T-05-02-03 | Information Disclosure | Config file bind mount | accept | Config file is operator-provided and read-only in normal usage; telldusd only parses it with libconfuse, no execution |
