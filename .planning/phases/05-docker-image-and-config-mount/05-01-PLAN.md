  <action>
    Create Dockerfile at repo root with two stages:

    Build stage (FROM debian:bookworm-slim AS build):
    - Set DEBIAN_FRONTEND=noninteractive
    - Install build dependencies: apt-get update -qq && apt-get install -y -q cmake build-essential pkg-config libftdi1-dev libconfuse-dev libusb-1.0-0-dev libcppunit-dev
    - Set WORKDIR /build
    - Copy CMakePresets.json and telldus-core/ source into /build
    - Run cmake --preset headless
    - Build with cmake --build build/headless --parallel 1 (single-threaded per Phase 3 QEMU findings)
    - Run tests with ctest --test-dir build/headless -R cppunit --output-on-failure; build fails if tests fail

    Final stage (FROM debian:bookworm-slim):
    - Set DEBIAN_FRONTEND=noninteractive
    - Install runtime packages with --no-install-recommends: libftdi1, libconfuse0, libusb-1.0-0, tini
    - Clean apt lists with rm -rf /var/lib/apt/lists/*
    - Copy artifacts from build stage:
      * telldusd -> /usr/local/sbin/
      * libtelldus-core.so* -> /usr/local/lib/
      * tdtool -> /usr/local/bin/
      * tdadmin -> /usr/local/bin/

    - Run ldconfig to update library cache
    - Set a placeholder ENTRYPOINT and CMD that will be refined in Plan 05-02 (use ["/usr/bin/tini", "--", "/bin/sh"] as interim)

    Ensure no Qt packages, no GUI components, and no build tools remain in the final stage.
  </action>

## Threat Model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host filesystem -> Docker build context | Untrusted files in repo could be copied into build stage |
| Docker build stage -> final image | Build tools and test artifacts must not leak into runtime image |

### STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Information Disclosure | Dockerfile build context | mitigate | .dockerignore excludes .planning/, .git/, and local artifacts; no .env or secrets copied into image |
| T-05-01-02 | Elevation of Privilege | Final image attack surface | mitigate | Multi-stage build strips compiler, headers, and build tools from final stage; only runtime libraries and production binaries remain |
| T-05-01-03 | Denial of Service | Build pipeline | mitigate | CppUnit tests fail the build if code is broken, preventing untested artifacts from reaching the final image |

- .dockerignore prevents context bloat
