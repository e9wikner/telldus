## Key Technical Context

### OUT OF SCOPE (Per Locked Decisions)
- **DUO-05 (Dimming):** D-07-08 explicitly states "Dimming, bell, and learn commands are out of scope for Phase 7"
- **DUO-06 (Sensor/Receive):** D-07-04 states "Sensor/receive path verification... are deferred to v1.x or v2"

### IN SCOPE: Error Path Verification (D-07-11)
- "When TellStick Duo is not physically connected, verify error paths: tdtool returns TELLSTICK_ERROR_NOT_FOUND or similar error codes"

### tdtool Error Codes (from RESEARCH.md)
| Exit Code | Meaning |
|-----------|---------|
| 0 | TELLSTICK_SUCCESS |
| 1 | TELLSTICK_ERROR_NOT_FOUND |
| 2 | TELLSTICK_ERROR_PERMISSION_DENIED |
| 3 | TELLSTICK_ERROR_DEVICE_NOT_FOUND |
| 4 | TELLSTICK_ERROR_METHOD_NOT_SUPPORTED |
| 5+ | Other communication/config errors |

### Error Scenarios to Test
1. **No hardware connected:** Container without --privileged, tdtool commands fail gracefully
2. **Invalid device ID:** tdtool --on 999 (device doesn't exist in config)
3. **Daemon not running:** tdtool returns connection error
4. **Malformed commands:** tdtool with invalid arguments
</context>
