## Key Technical Context

### TellStick Duo USB IDs
- Vendor ID (VID): 0x1781
- Product ID (PID): 0x0C31
- lsusb output pattern: "Bus XXX Device YYY: ID 1781:0c31 Multiple Vendors Telldus TellStick Duo"

### USB Passthrough Requirements
- Container must run with `--privileged` (D-06-01, D-07-05)
- Device access via `/dev/bus/usb` (D-06-03: libftdi opens by VID/PID, not device path)
- Detection command: `docker exec telldus lsusb | grep "1781:0c31"`

### Error Path Verification
Per D-07-11, when TellStick is not connected, verify error paths return appropriate non-zero exit codes.
</context>
