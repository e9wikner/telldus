# 06-02: Run telldusd as the Container Main Process

## Objective

Document and validate that telldusd runs correctly as the container's main process with proper signal handling, foreground operation, and logging to stdout/stderr.

## Context

Per 06-CONTEXT.md decisions D-06-07 through D-06-09, the container uses tini as PID 1 for signal forwarding, telldusd runs with --nodaemon for foreground operation, and SIGTERM/SIGINT trigger graceful shutdown. This plan documents this runtime behavior and ensures the daemon starts successfully in the containerized environment.

**Key decisions to implement:**
- D-06-07: tini as PID 1 (already in Dockerfile from Phase 5)
- D-06-08: telldusd --nodaemon for foreground operation
- D-06-09: SIGTERM/SIGINT trigger graceful shutdown
- D-06-16: Logging to stdout/stderr only

- [ ] Documentation explains signal handling (SIGTERM graceful shutdown)
