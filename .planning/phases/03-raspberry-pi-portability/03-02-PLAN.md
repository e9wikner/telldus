  </read_first>
  <action>
    Execute the Docker multi-arch build for linux/arm64 per D-03-01, D-03-02, and D-03-06:
    - Run docker with --rm --platform linux/arm64 and debian:bookworm-slim
    - Mount the repository read-only: -v $(pwd):/src:ro
    - Set DEBIAN_FRONTEND=noninteractive
    - Install dependencies via apt-get update -qq && apt-get install -y -q cmake build-essential pkg-config libftdi1-dev libconfuse-dev libusb-1.0-0-dev libcppunit-dev
    - Copy source to writable directory: cp -r /src /work
    - Change to /work/telldus-core
    - Run cmake -B build/headless with exact cache variables: FORCE_COMPILE_FROM_TRUNK=TRUE, BUILD_TDTOOL=TRUE, BUILD_TDADMIN=FALSE, ENABLE_TESTING=TRUE, FTDI_ENGINE=libftdi
    - Run cmake --build build/headless --parallel $(nproc)
    - Set timeout to at least 600 seconds (10 minutes) to account for QEMU emulation overhead per RESEARCH.md pitfall 2.
    Do NOT reuse a host-created build directory. Do NOT build directly against the read-only mount.
    If the build fails, capture the exact error output for Wave 3 analysis per D-03-09.
  </action>
  <acceptance_criteria>
    - docker run command exits with code 0
    - build/headless/service/telldusd exists inside the container
    - build/headless/client/libtelldus-core.so exists inside the container
    - build/headless/tdtool/tdtool exists inside the container
    - build/headless/tests/TestRunner exists inside the container
  </acceptance_criteria>
  <verify>
    <automated>
      docker run --rm --platform linux/arm64 \
        -v "$(pwd)":/src:ro \
        -e DEBIAN_FRONTEND=noninteractive \
        debian:bookworm-slim \
        bash -c '
          set -e
          apt-get update -qq
          apt-get install -y -q cmake build-essential pkg-config libftdi1-dev libconfuse-dev libusb-1.0-0-dev libcppunit-dev
          cp -r /src /work
          cd /work/telldus-core
          cmake -B build/headless -DFORCE_COMPILE_FROM_TRUNK=TRUE -DBUILD_TDTOOL=TRUE -DBUILD_TDADMIN=FALSE -DENABLE_TESTING=TRUE -DFTDI_ENGINE=libftdi
          cmake --build build/headless --parallel $(nproc)
          test -f build/headless/service/telldusd
          test -f build/headless/client/libtelldus-core.so
          test -f build/headless/tdtool/tdtool
          test -f build/headless/tests/TestRunner
          echo "BUILD_OK"
        '
    </automated>
  </verify>
  <done>All three headless targets (telldusd, libtelldus-core.so, tdtool) and TestRunner compile successfully inside the Debian aarch64 container.</done>
